# Edversse Edge Project

This repository contains the **Edversse Edge** website project.

## Project Structure

- `platform/` — React + Vite frontend application

## Tech Stack

- React
- React Router
- Vite
- ESLint

## Getting Started

1. Open terminal in the project folder:
   - `/home/runner/work/edversseedge/edversseedge/platform`
2. Install dependencies:
   - `npm install`
3. Start development server:
   - `npm run dev`

## Available Scripts

From the `platform/` directory:

- `npm run dev` — start local dev server
- `npm run build` — build for production
- `npm run preview` — preview production build
- `npm run lint` — run lint checks
